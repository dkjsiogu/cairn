# 29 · 玩的时候和找东西的时候

> 0.44。前面的版本把「装」和「救」做扎实了，这一版回到玩家每天碰到的两件事：**游戏开着的时候**启动器该怎么样，以及**东西多了以后**怎么找到它。顺带把界面的框架理了一遍，让以后加页面、加弹窗不用改十几个地方。

## 1. 游戏开着的时候

以前「游戏运行」是一个后台任务，和安装、下载抢同一个位置：玩的时候不能装别的版本，也看不到游戏到底起来没有，卡住了只能去任务管理器。

| 以前 | 现在 |
|---|---|
| 运行中就是一个圆点「游戏运行中」 | 侧栏每个在玩的版本一行：名字、「正在准备 / 正在启动 / 运行中 · 12 分钟」，点它看这一局的输出 |
| 游戏卡死只能去任务管理器 | 「结束游戏」，两步确认；先请游戏自己退，3 秒后还在就强制结束 |
| 玩的时候不能装、不能下 Mod | 游戏不占任务：装别的版本、给别的版本下 Mod、导入整合包都照常；只有正在玩的那个版本不能改 |
| 一次只能开一个 | 不同的版本可以同时开 |
| 启动之后要自己点「单人游戏」再找世界 | 启动台「最近世界」旁边一个「进入」，存档页每个世界一个「进入」：开游戏直接进这个世界（1.20 起） |
| 玩了多久不知道 | 每个版本记游玩时长和次数，版本列表按最近玩过排，写着「3 天前玩过」 |

**怎么知道窗口出来了：** 游戏输出里出现 `Backend library`、`LWJGL Version`、`Sound engine started` 或贴图图集这几种行之一，就是窗口已经建好。认不出的版本两分钟后也当它起来了。

**游戏启动后收起启动器**（设置 › 游戏，默认关）：窗口出来后把启动器收到任务栏，所有游戏都退出后放回来。

**输出不再会卡住游戏：** 以前按 UTF-8 一行一行读游戏输出，碰到不是 UTF-8 的字节（Windows 上的中文路径、GBK 的玩家名）读取线程就停了，管道写满后游戏会卡住。现在按字节读，坏字节换成 `�`。同时加上 `-Dstdout.encoding=UTF-8`，Java 19+ 在 Windows 上的输出不再乱码。

## 2. 坏了能救，就在出事的那一刻

0.20 起每次改内容前都留恢复点，但游戏崩了以后，玩家得自己想到去「内容 › 恢复点」里找，还得猜是哪一个。

现在启动器记着每个版本**上次正常玩完是什么时候**（正常退出且玩了 30 秒以上，或者不管怎么退出玩够了 10 分钟；被玩家结束的不算）。游戏异常退出时，如果那之后改过内容，底部提示多一个「退回改动」：

- 说清楚上次正常玩是什么时候、那之后改过几次、要退回到哪个恢复点之前；
- 世界存档不动；
- 退回前再留一份现在的，退错了还能回来。

没正常玩过、或者那之后没改过内容，就不给这个按钮——退回也救不了。

## 3. 东西多了以后

**`Ctrl+K` 命令面板。** 打几个字就到：版本名（`Enter` 切换到它，`Ctrl+Enter` 直接启动）、当前版本的世界（能直接进的直接进）、五个页面、设置的四栏、常做的事（检查内容更新、恢复点、启动参数、复制版本、导出、打开文件夹、换主题、换账户）。设置里的词也能搜到：打 `zoom`、`内存`、`镜像` 都能找到对应的那一栏。找不到时最后两条是「在已安装的内容里找」「去发现里搜」。右下角写着 `Ctrl+K 找任何东西`，点它也能打开。

**版本页能搜**（版本多于 6 个时出现，`Ctrl+F`）。启动台的「切换版本」改成列表：版本名、游戏版本和加载器，在玩的有圆点，多于 8 个时能搜。

**截图页 `Ctrl+F`** 以前被全局快捷键吃掉了，现在能用。

## 4. 新功能

- **复制版本**（版本页按钮、右键菜单、`Ctrl+K`）：Mod、配置、资源包和启动参数照搬，存档可选；日志、备份、恢复点不带。游戏本体硬链接，不多占空间。先写到 `.名字.part`，全部好了才改名，中途取消不留半个版本。
- **拖世界进来**：世界文件夹、装着几个世界的 `saves` 文件夹、或者里面有 `level.dat` 的 zip（包括 Cairn 自己的备份），拖到窗口上就导进当前版本（在存档页是上面选的版本），重名的加 `(2)`，做完跳到存档页选中它。
- **版本详情的数字能点**：Mod、资源包、光影去内容页的那一类，存档去存档页。右边写这个版本玩了多久。
- **界面缩放**（设置 › 启动器，80%–150%，也能 `Ctrl +` / `Ctrl −`）。
- **记住窗口**：上次选的版本、窗口大小、是否最大化、缩放，下次打开还是那样。
- **完成提示自己消失**：底部的完成提示 6 秒后消失，指着它不走；错误留到关掉。所有页面共用这一条，启动台也是。
- **不在前台时提醒**：安装做完、游戏退出时窗口不在前台，任务栏上闪一下。
- **命令行**：`cairn-cli launch <版本> --world <存档>` / `--server <地址>`。

## 5. 设置分栏

设置以前是一个长卷，内容越加越多。现在左边四栏：

| 栏 | 内容 |
|---|---|
| 游戏 | 账户、Java（悬停看找到的全部 Java）、内存和回收器、游戏启动后收起启动器 |
| 启动器 | 外观、缩放、减少动效、截图写入地点和人物、自动更新、下载源 |
| 存储 | 当前版本和数据目录、清理不用的文件 |
| 关于 | 版本和更新、项目主页、日志、重新读取版本、快捷键 |

## 6. 框架

| 以前 | 现在 |
|---|---|
| 五个 `show_*` 布尔值表示在哪一页，进每一页要把别的四个关掉（散在 60 多处） | `Page` 一个枚举，`App::go(page)` |
| `ui.json` 手写读写，不认识的键写回时丢掉 | `prefs.rs`：`UiPrefs::load/save`，只换自己认识的键，先写临时文件再改名 |
| 「有没有弹窗开着」在快捷键里手写一串 | `App::modal_open()` 一处，新弹窗加一行 |
| 每个弹窗自己写遮罩、外框、Esc | `widgets::dialog()` 和 `dialog_title()` |
| 游戏运行是 `Task::Launch`，`play.started`、`running_row` 只能记一个 | `play::Session`：每局一个，带结束用的 `launch::Handle`、阶段、日志位置 |
| `launch::launch` 一直等到游戏退出 | `launch::start` 返回 `Game`，`wait()` 等退出，`handle().stop()` 从别的线程结束；命令行的 `launch` 包一层 |

core 新增：`played`（游玩记录）、`launch::{start, Game, Handle, QuickPlay, can_quick_play_world}`、`versions::duplicate`、`saves::{is_world, import_world}`。

## 7. 验证

- `cargo test --workspace`：core 168 项、界面 27 项（新加：快速进入的参数、地址拆分、非 UTF-8 输出不中断、游玩记录、复制版本、导入世界、命令面板的匹配、设置文件保留未知键、启动台标题、崩溃退路选哪个恢复点）。
- Xvfb 里真实启动原版 1.21.1：「正在启动」→ 窗口出来后「运行中」→ 侧栏一行 →「结束游戏」两步确认 → 进程结束，记下 66 秒、不算正常玩完。
- `cairn-cli launch --dry-run --world / --server` 核对参数：1.21.1 和 1.20.1 都是 `--quickPlaySingleplayer` / `--quickPlayMultiplayer`。
- 深浅两套、1120×720 和 900×620 截图核对启动台（运行中、结束确认）、版本页、存档页、设置四栏、命令面板、复制版本、退回改动。

## 8. 还没做到的

- 「进入」只给 1.20 起的版本；更老的版本只能连服务器（`--server`），不能直接进单人世界。
- 结束游戏在 Windows 上是直接结束进程，没有先请它自己退。
- 游玩时长只从 0.44 开始记，以前玩的不算。
- 同时开两个版本时，崩溃退路只看最后退出的那一个。
